# Hachidori 0.2.0

Hachidori has a new experimental Theme Store, more faithful dictionary rendering, and more ways to control when a popup opens and stays open. Monochrome dictionary images now follow the text colour, including in Windows contrast themes. This release also makes Anki glossaries easier to read and fixes lookups in asbplayer's video frame and fullscreen player.

## Highlights

### Choose how your popup looks

**Settings → Advanced → Experimental features → Theme Store** unlocks three bundled renderers in **Design**. **Default** keeps the familiar rich popup and its colour palettes. **Nazeka** offers a compact, familiar layout; **Plain** shows just definition text. The Store previews each renderer and switches it immediately. The feature is off by default while it is still evolving; switching it off keeps your selected theme for when you turn it back on. Nazeka currently omits Note/custom buttons, dictionary tabs, pitch graphs and media. (#380)

### Dictionary entries look more like Yomitan

Definitions now use Yomitan-style glossary markup and CSS, including list markers, links, tables, image captions, line breaks and language tags. Structured content's inline styles also follow Yomitan more closely. Monochrome dictionary images, such as stroke-order strips and gaiji, paint in the popup's text colour in both the card and enlarged preview. Windows forced-colors mode uses the system text colour so the image remains visible. (#366, #381, #329, #389)

### More control over scanning and nested popups

You can choose **No key** for hover scanning or hold the middle, Back or Forward mouse button to scan. A child popup can wait for the activation key or a click, and **Hide popup on cursor exit** has its own delay. Popups beside a word use less space and sticky child popups stay open while you move between them. These controls also work with the GameSentenceMiner overlay. (#374, #378, #375, #382, #371)

### Smaller Anki cards, if you want them

The new **Smaller Anki cards** experimental switch writes compact glossary HTML instead of repeating popup CSS in each rich definition field. Text, useful dictionary markup and image sizing stay; the existing Anki output is unchanged when the switch is off. In the PR's five-entry Jitendex example, the rich fields fell from 70,508 to 18,963 bytes with the switch on. (#377)

## Reading

- Hover lookups now work in asbplayer's in-page video frame and compatible fullscreen players. (#338)
- An experimental **Google Docs** switch enables lookups in Docs' canvas-rendered text. It is off by default and depends on Google's annotation layer. (#328)
- Pitch accent badges can show their dictionary names, and pitch furigana draws connected levels on one row. (#370, #372)
- Frequency tags show the dictionary's full value by default; **Abbreviate large numbers** in Design restores `k`/`m`/`b` labels. When averages are shown, per-dictionary tags remain hidden in the DOM for Custom CSS. (#373, #383)
- Switching Library tabs no longer moves the tab strip. (#368)

## Anki and audio

- Anki glossaries keep line breaks and separate list items; exported images preserve `em` sizing. (#367, #327)
- **Detect local audio** now works with the AnkiWeb Local Audio Server add-on. If detection failed during first-run setup, click **Detect local audio** once after updating. (#369)
- AnkiConnect's unknown-reason cloze refusal now names the cloze rule, and deferred audio is retained when an Anki add-on rewrites another field. (#376, #326)

## Compatibility changes

- Hachidori now ships a Chrome MV3 extension and source archive only. Firefox support and its XPI release have been removed. (#339)
- The experimental media-mining recorder and its controls have been removed. Ordinary text and dictionary mining, downloadable pronunciation and the separate `{screenshot}` Anki field remain. (#341)

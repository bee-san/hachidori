# 🐦 Hachidori 0.2.2

More useful pitch accent, better furigana, and fewer interruptions while reading. This release adds pitch colours and an overline style, lets you look up Japanese inside text boxes, speeds up Anki button readiness, and fixes backup and restore failures.

## 🎵 Pitch accent at a glance

The Default theme gains two options under **Design → Pitch accent**:

- **Furigana pitch style → Overline** draws a line above high morae and a hook where the pitch drops, matching the pitch list. **Contour** remains the default.
- **Show pitch accent colours** colours headwords and pitch lines by accent group: **blue** for 平板 (heiban), **red** for 頭高 (atamadaka), **orange** for 中高 (nakadaka), **green** for 尾高 (odaka), and **purple** for 起伏 (kifuku). It is off by default.

Both update open popups and the Design preview immediately. Pitch colours follow the selected pitch dictionary, and Windows contrast themes keep using system text colours. (#461, #463)

Furigana also gets smarter. Mixed kana/kanji words no longer duplicate readings, as ゴミ箱 could previously do. When a split is ambiguous, bundled KANJIDIC readings can resolve it: **好き嫌い → 好(す)き嫌(きら)い**, and **長い間 → 長(なが)い間(あいだ)**. The same split reaches the popup, Anki's `{furigana}` / `{furigana-plain}`, and the scanning API. (#460, #462)

## 📖 Smoother reading

- **Look up Japanese inside text boxes.** Hover over words in text and search inputs or textareas, including Jisho's search field. Scrolled fields work too, and you can keep typing normally. (#441)
- **Keep your place when switching apps.** Switching tabs, windows, or applications now keeps the popup and your Note draft open. (#444)
- **Fit more definitions on screen.** The Default theme's new **Design → Definitions → Compact glossaries** option puts compatible glossary items on one line, separated by `|`. (#445)
- **See the settings your theme supports.** Design and Settings search now show the selected theme's controls. JL and Bee's Theme also update their pitch markers immediately when you change the pitch switch or dictionary. (#439)
- **Mine cleaner sentences from selections.** Selecting a word now finds its surrounding sentence the same way hovering does, keeping ruby readings, hidden text, and page scripts out of the sentence and custom links. (#447)

## ⚡ Faster Anki checks and better integrations

- **Anki buttons become ready with fewer requests.** Results sharing an Anki Template are checked in batches, and compatible note types' field discovery is batched too. Popups with many results spend less time waiting on AnkiConnect. (#451, #452)
- **Save the source URL.** Add `{url}` to an Anki field template for a clickable link to the page you mined from, or `{url-plain}` for its address. Both work when mining through a linked browser. (#443)
- **Let other tools read your Anki Templates.** Hachidori Relay **0.0.5** adds Yomitan-compatible `/ankiCardFormats`, allowing tools such as GSM Companion, Yomine, and asbplayer-mining to discover your saved formats. **Settings → Sharing** downloads the updated relay. (#448)

## 📚 More faithful dictionaries

- Definition tags now use the dictionary's categories, colours, descriptions, and ordering. Multiword Jitendex tags stay intact, and Anki exports use the same tags. **Reimport an existing dictionary to pick up its tag-bank metadata.** (#446, #449)
- Frequency dictionaries storing ranks as text, such as monogatari's `324/37459`, now display their values. Existing installations work without reimporting. (#442)
- Frequency values stay in dictionary order, making the displayed values easier to compare with the average rank. (#431)
- Dictionary images specifying only width or height now keep their natural proportions, fixing stretched accent glyphs. (#434)
- MDict imports handle key rules, redirect chains, legacy stylesheet encodings, and `<font size>` more faithfully. Import progress also explains any skipped records, unresolved aliases, or missing/unreadable resources beneath the **Imported** line. (#453, #449, #450)

## 🛠️ Fixes and polish

- Fixed `outputSize` errors when exporting backups or restoring them. (#420)
- Background request failures now return an error response instead of leaving the caller without a reply. (#428)
- Added a one-minute walkthrough to the README, showing real lookups, mining, the personal dictionary, definition blur, and themes. (#455)

# Hachidori 0.2.1

This release adds two new Theme Store themes, JL and Bee's Theme, and a tidier Settings page with one clear label per setting. Popups now stay put on live chat feeds and in GameSentenceMiner's OCR overlay. The default popup gets definitions on screen sooner. It also fixes mining from clicked-kanji dictionary groups, Anki refusing definitions that contain cloze text, and flickering image previews, and it shows the extension's full memory use in Settings.

## Highlights

### Two new themes in the Theme Store

**JL** follows [rampaa/JL](https://github.com/rampaa/JL)'s popup, with JL's colours, font sizes, spacing and Meiryo. **Bee's Theme** keeps JL's compact layout and adds formatted definitions (lists, tables, furigana, links and images), dictionary-group tabs, one audio/Anki/edit icon group per entry, enlarged image previews and a Girlypop blush-and-violet palette. The Store now has **Previous themes** and **Next themes** buttons, so you can see every theme even on a wide window or with overlay scrollbars. Nazeka and Plain lay out structured glossaries the way JL does: tags are spaced and readings are bracketed, and there are no runs of blank lines. The Theme Store is still an experimental feature under **Settings → Advanced → Experimental features**. (#395, #405, #412, #413, #414, #416, #393, #392, #394)

### Settings that say what they do

Settings now has one label per setting, and each control sits where you'd look for it:

- The two popup timers are together under **Reading → Popup closing**, as **Grace period to reach the popup** and **Delay after leaving the popup**. They were called *Hide delay* and *Hide popup on cursor exit* in different groups.
- The frequency-blur dictionary defaults to **Same as sorting**.
- Each dictionary picker names its role.
- **Show the audio button** is now in **Audio**.
- The personal dictionary switches are in **Library → Personal dictionary**.
- The unused hover-delay option is gone.

Existing settings and backups carry over unchanged. (#410)

### The popup stays where it opened

On pages whose text keeps moving, such as a live-stream comment feed, the popup used to chase the word as it scrolled and closed when the word scrolled away or was removed. Like Yomitan, it now stays where it opened until you close it with Escape, the close button, an outside click, cursor exit or a new lookup. Mining, audio and Back still work after the source text has gone. (#411)

### A more compact default popup

The default theme wastes much less space above your definitions. The compact summary now sits beside the headword instead of under it, and icon-only toolbars no longer reserve 270 px. Controls, tabs, labels and padding are tighter. Definition text stays at 16 px. For 食べる in the default 560 × 420 popup, the first definition moves up from 240 px to 154 px below the top and 8 lines fit instead of 5. The kanji view also loses its stray scrollbar. (#418)

## Reading

- In GameSentenceMiner's OCR overlay, moving the mouse off the OCR text or switching focus to the game no longer closes the popup. Browser tabs behave as before. (#407)
- The new **Design → Definitions → Image hover preview** setting offers Off, **Large images only** (default) and All images. Small inline glyphs, such as `em`-sized SVG brackets and labels, no longer flash a full-screen preview as you scroll past them. (#408)
- **Settings → Advanced → Memory** shows the extension's total memory next to the engine heap, including how much sits outside the heap. If Hachidori seems to grow over a long session, this is the number to watch. `docs/memory.md` explains what it covers. (#417)

## Anki

- Clicking a kanji whose Clicked-kanji dictionary is a group containing a kanji-only dictionary (KANJIDIC, 漢字辞典オンライン, …) now lets you mine it. The mining button used to fail with `Cannot read properties of undefined (reading 'split')`. Thanks to @jangirdnick for tracking down the cause in #409. (#415)
- Definitions that contain literal cloze text, such as `{{c1::より}}` in some grammar dictionaries, can now be added to Basic and other non-Cloze note types. The braces display as normal. (#406)
- With **Smaller Anki cards** on, rich definition fields no longer end with a *Rules / Deinflection* footer. (#404)

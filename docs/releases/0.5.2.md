# 🐦 Hachidori 0.5.2

Netflix subtitle notes capture the video's picture again, using Netflix's preview image only when the captured video is black. A new experimental switch saves ordinary Anki screenshots as AVIF. The configuration bridge lets local AI clients set up Hachidori through hachidori-mcp.

## 📺 Netflix screenshots

With **Settings → Advanced → Experimental features → Netflix mining** on, a note made from a subtitle now takes `{screenshot}` from the video itself, cropped to its picture with Netflix's subtitles and controls hidden. If protected playback makes that capture black, Netflix's timeline preview image stands in for it. The preview has lower resolution and can show a nearby moment rather than the exact frame. (#747)

In 0.5.1, Netflix mining always used the preview. A note on a Netflix watch page that is not made from a subtitle still uses it. (#747)

## 🖼️ AVIF screenshots (experimental)

**Settings → Advanced → Experimental features → AVIF screenshots** saves uncropped local Anki screenshots as smaller AVIF images when the browser can encode them. It starts off; encoding can take longer. If encoding fails, the screenshot stays JPEG. Cropped video captures and screenshots sent to a linked browser keep their existing formats. (#750)

## 🧩 MCP configuration

[hachidori-mcp](https://github.com/bee-san/hachidori-mcp) lets a local AI client set up languages, edit settings and install user scripts through the existing Anki relay. Keep Anki and the sharing browser open, with Sharing showing **Sharing through Anki**. No new Anki add-on is needed; an empty installation needs a dictionary before it can share. (#746)

The bridge reports settings and their available choices, languages, dictionaries, themes and user-script registration. Writes use Hachidori's existing validation and revision checks, and browser permission to run JavaScript still needs your click. See the [MCP guide](https://github.com/bee-san/hachidori/blob/main/docs/mcp.md) for setup and the supported requests. (#746)

## 📦 Downloads

- **`*-chrome.zip`**: extract it, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the extracted folder. To update an existing unpacked installation, replace its files and click **Reload**.
- **`*-firefox.zip`**: for Firefox 153 or newer, the same package this release submits to addons.mozilla.org.
  - Until Mozilla lists it, open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on…** and select the ZIP.
  - To keep it installed, use Firefox Developer Edition, Nightly or ESR, as [the Firefox guide](https://github.com/bee-san/hachidori/blob/main/docs/firefox.md#install) describes.
- **`*-source.zip`**: the matching complete source, including the engine and the sources of bundled dependencies.
- **`*-SHA256SUMS.txt`**: checksums for all three packages.

Chrome 128 or newer and Firefox 153 or newer are supported. Your dictionaries and saved settings are kept, and you don't need to reimport anything.

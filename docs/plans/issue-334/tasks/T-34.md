## Goal

c07: "can we straight up have a yomitan theme". Its own popup emitting Yomitan's DOM vocabulary (`.entry[data-type=term]` > `.entry-header` (`.actions`, `.headword-list` > `.headword-term`/`.headword-reading`) + `.entry-body-section[data-section-type=frequencies|pronunciations|definitions]` > `.definition-item[data-dictionary]` > `.definition-tag-list` + `ul.gloss-list`; `.tag` > `.tag-label`), styled by a port of Yomitan's display.css, so users' Yomitan Custom CSS snippets work.

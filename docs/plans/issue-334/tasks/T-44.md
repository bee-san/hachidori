## Goal

Refresh fetches `dist/index.json` (If-None-Match, ≤ 1 MiB, schema, final-URL check) into `themes.catalogue`; palettes and variants from it can be used (colour values stored and compiled locally by T-23), updated and removed; renderer themes show "Arrives with Hachidori x.y"; screenshots load only when a detail pane opens; optional weekly check, default Off. No CSS or code download exists.

## Goal

c26: keyboard mining, autoplay and audio must not break when a renderer omits or moves a control. Actions work by result, with state events; buttons are optional views of that state.

## Files (ownership boundary)

- **edit** [audio-content.js](https://github.com/bee-san/hachidori/blob/main/extension/audio-content.js#L226-L290) — `play(owner, result, {source})`, autoplay without a button, state subscribe; `bind` stays for painting
- **edit** [anki-content.js](https://github.com/bee-san/hachidori/blob/main/extension/anki-content.js#L465-L580) — `mine(owner, result, mode)`, `state()`, subscribe; `controls()` only when a mine-button component is requested; custom Anki buttons by descriptor id (520-521)
- **edit** [reader.css:1481](https://github.com/bee-san/hachidori/blob/main/extension/render/reader.css#L1481) — `showPopupAudioButton=false` → the button is not rendered (instead of CSS-hidden); autoplay and keybind unaffected

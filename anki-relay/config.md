Hachidori Relay lets the Hachidori browser extensions on this computer share one set of dictionaries, personal entries, lookup counts and settings while Anki is open. It needs no setup: a Hachidori that shares itself and the browsers that link to it find the relay on the port below.

- `port`: the port Hachidori's Sharing uses, 8771 unless you changed it under **Settings → Sharing** in Hachidori. Change it here only if you changed it there too, then restart Anki.
